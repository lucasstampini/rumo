# RUMO

Marketplace peer-to-peer de aluguel de carros. Protótipo feito para a disciplina de empreendedorismo.

- `index.html`: app navegável (mapa da bolha Butantã, reserva, retirada com vistoria, painel do proprietário)
- `demo.html`: vídeo demo narrado

Site estático, sem build: abra `index.html` no navegador ou publique com GitHub Pages.
